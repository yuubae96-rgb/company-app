書き出しの即時起動設定

最初に管理者が1回設定します。設定後は、動画の受付時にサーバーへ起動を要求し、定期チェック待ちを使いません。

設定状況を確認しています…

① 専用キーを作る

GitHubのキー作成画面を開く
  1. Repository access → Only select repositories を選び、company-app だけを指定します。
  2. Repository permissions → Actions：Read and write を確認します。
  3. Generate token を押し、表示された github_pat_ で始まるキーをコピーします。
キーはサーバーに暗号化して保存します。チャットへ貼り付ける必要はありません。キーの期限が切れた場合は、このページで更新できます。
